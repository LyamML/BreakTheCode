# Alerte cailloux cosmiques

Votre flotte vient d'arriver dans le _secteur Gamma-42_, une zone notoirement instable de la bordure galactique. Les scanners longue portée de votre vaisseau amiral ont détecté une densité anormale de débris spatiaux. Pour éviter tout accident, une sonde de reconnaissance a été lâchée dans la zone afin de la cartographier.

La sonde a transmis une série d'images en **noir et blanc** représentant l'espace environnant où chaque pixel blanc représente un astéroïde. Un **champ d'astéroïdes** est un amas d'astéroïdes situés dans un rayon maximum de **5px** les uns des autres sur les images.

Comptez le nombre de **champs d'astéroïdes** présents dans la zone afin de déterminer s'il est possible d'organiser une mission d'extraction minière ou s'il est plus judicieux de s'éloigner pour éviter d'endommager la flotte. Un astéroïde isolé est compté comme un champ d'astéroïdes.

### Input
Suite d'images situées à une distance 1px représentant un espace en 3 dimensions.

### Output
Le nombre de **champs d'astéroïdes** présents dans la zone
