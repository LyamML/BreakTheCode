# Hal, c'est quoi le code ?

Ca doit être ça .. Voilà maintenant plus de 3h que vous vous échinez à retrouver le code de votre porte-document qui contient des coordonnées de planètes et routes stellaires. 
Impossible de choisir le chemin optimum pour le [exo opti] sans son contenu. On pourra toujours arriver à destination, mais si on peut s'éviter des détours c'est toujours mieux.

Ce code, il n'est vraiment pas compliqué pourtant ! 3 caractères, 3 lettres en minuscule plus précisément. Le hic, c'est que ce porte document est sécurisé, et il ne vous reste plus qu'un seul essai avant qu'il ne soit verrouillé. Nul besoin de vous rappeler que vous n'êtes pas prêt de pouvoir le déverrouiller, il faudra repasser par le QG et ce n'est pas du tout prévu à court terme.

Résigné, vous entendez la douce voix de Hal qui vous dis "Je peux vous donner le code si vous le désirez". 

Hal, votre ordinateur de bord d'habitude dévoué, a décidé de vous jouer un petit tour mesquin.

En plus de vous avoir laissé mariner pendant des heures, il ne vous donne pas le code directement, celui-ci est caché dans la chaîne de caractère qu'il vous fourni.

Il ajoute "Pour trouver le code, c'est très simple, c'est la chaîne qui se répète le plus de fois".

Bon, ça ne va pas vous arrêter, dans un soupir vous vous mettez au boulot.

**Input**
Fichier "rahaha_le_code_est_la.txt"
1 ligne contenant la chaîne de caractère où est caché le code

**Output**
Le code qui se répète le plus dans la chaîne de caractère.

**Exemple**
Input : "ABCDEBCDABDC"
Output : "BCD"
