# Un message codé

Vous êtes le chef sur Terre d’une opération d’exploration qui est partie à la recherche d’une nouvelle planète habitable.

Vous avez reçu un message radio sous forme d’un fichier audio .wav de l’équipe partie en exploration. Selon les instructions, ce message doit contenir le nom de la planète habitable sur laquelle ils sont arrivé, ainsi que l'itinéraire préconnisé par l'équipe d'exploration.

Il vous faut décoder ce message afin de connaitre la planète habitable.

**Input**

Fichier message.wav : Le message audio codé.

**Output**

Le nom de la planète d’où provient le message

**Exemple**

Input :

Fichier audio décrypté : ``Je suis sur Mars``

Output : `Mars`
